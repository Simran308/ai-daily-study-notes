# Where to research

Prefer primary sources. Use aggregators only to *find* stories, then confirm the facts at the source.

## Primary (official)
- Anthropic news & docs: anthropic.com/news, platform.claude.com/docs
- OpenAI: openai.com/news, platform.openai.com/docs
- Google DeepMind / Gemini: deepmind.google, blog.google/technology/ai, ai.google.dev
- Meta AI: ai.meta.com/blog
- Mistral: mistral.ai/news
- DeepSeek, Qwen (Alibaba), Microsoft (Phi), NVIDIA: their GitHub / Hugging Face org pages
- Hugging Face: huggingface.co/blog, model cards on the Hub
- Framework release notes: GitHub releases for LangChain/LangGraph, LlamaIndex, CrewAI, vLLM, Ollama, MCP (modelcontextprotocol.io)

## Discovery (to find what's new)
- Hugging Face trending models & papers (huggingface.co/papers)
- arXiv cs.CL / cs.AI
- Simon Willison's blog (simonwillison.net): practical, hype-free
- Latent Space, The Batch (deeplearning.ai), Import AI newsletters
- Hacker News front page, r/LocalLLaMA

## Use cases
- Company engineering blogs (Shopify, Stripe, Uber, Notion, Duolingo, Airbnb, etc.)
- Vendor customer stories, which are often thin on detail, so look for the engineering write-up behind them
